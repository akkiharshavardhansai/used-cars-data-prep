# Used Cars Data Preprocessing Project

## Objective
Prepare used car dataset for machine learning price prediction.

## Steps Performed
- Loaded dataset from Kaggle
- Cleaned missing values and duplicates
- Converted categorical variables using encoding
- Split data into training and testing sets
- Built baseline model using mean prediction

## Result
Baseline MAE: ₹440,053

## Tools Used
Python, Pandas, Scikit-learn, Google Colab
